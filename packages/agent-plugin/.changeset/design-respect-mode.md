`design` skill 서술을 바로잡고 기성 디자인 시스템 존중 모드를 넣는다. README·플러그인 문서의 `design` 설명이 "Figma → 등록용 이미지 에셋"으로만 적혀 있던 것을 화면 생성·수정, 품질 채점, 등록용 이미지 자산(Figma는 선택)으로 정정한다. 프로젝트에 심는 디자인 가이드 캐리어 문구도 정정한다(가이드 마커 v2). 기성 디자인 시스템이 감지되면 기본 토큰과 전역 CSS를 주입하지 않고 프로젝트 시스템을 따르며, 플랫폼·안전 하드 규칙만 강제한다. 라우팅 반증 문구를 보강하고, 템플릿 사본이 정본에서 벗어나는 drift를 검증에 추가한다.
