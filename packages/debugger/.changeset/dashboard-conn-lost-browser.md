대시보드 두 가지를 고쳤다.

- debugger daemon이 끊기면 상태 배지만 "연결 끊김"으로 바뀌고 큰 화면은 "폰이 연결됐어요"로 남던 모순을 없앴다. 이벤트 스트림(SSE)이 끊기면 큰 화면도 즉시 "debugger와 연결이 끊겼어요"(폰 연결 상태를 확인할 수 없고, debugger가 다시 뜨면 자동으로 이어지며, 계속 이러면 Claude에게 다시 연결해 달라고 요청하라는 안내)로 바뀐다. 터널이 끊겼을 때의 기존 오류 화면과는 원인이 달라 별도 패널이다. 스트림이 다시 이어져 상태가 오면 그 상태에 맞는 화면으로 돌아오고, 최종 폴백(watchdog)은 그대로다.
- 환경 변수 `AIT_DEBUGGER_BROWSER`로 대시보드를 열 브라우저 명령을 지정할 수 있다. 셸 없이 인자 배열로 실행하고 토큰이 붙은 대시보드 주소를 마지막 인자로 넘긴다(공백으로 나누고 따옴표로 묶거나, `["명령","인자"]` JSON 배열). 지정하면 그 명령만 쓰고 실패해도 기본 브라우저로 넘어가지 않는다. 지정하지 않으면 기존 동작 그대로다. 표준 `BROWSER` 변수는 읽지 않는다. 토큰은 결과·로그·오류에 남지 않는다.
