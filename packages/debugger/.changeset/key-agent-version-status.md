`get_status`에 `keyAgent`를 추가했습니다. relay 키를 들고 있는 key agent가 응답하는지, pid와 시작 시각, 버전을 보여 줍니다. key agent는 업그레이드 뒤에도 이전 버전이 계속 떠 있을 수 있는데, 지금까지는 어느 버전이 키를 내주는지 알 수 없었습니다. 버전을 알리지 않는 이전 agent는 `unknown (<=0.5.0)`으로 표시하고, 데몬과 버전이 다르면 이전 버전이라는 안내와 agent가 바뀌는 시점을 함께 알려 줍니다. 연결하지 못하면 그렇게 표시합니다. 키나 토큰은 출력하지 않습니다.
