폰 확인 창 표시를 다듬었다. 코드에 섞인 눈에 안 보이는 문자(U+2028·U+2029 줄바꿈, 방향 제어, 폭 없는 문자, 제어 문자)를 줄바꿈이나 `[U+XXXX]` 표시로 드러내고 개수를 알려 준다. 빈 줄이 길게 이어지면 한 줄로 접어 보여 주고, 코드 상자 아래에 가려진 줄이 있으면 "아래에 N줄 더 있어요"를 띄운다. 확인 창은 페이지의 스타일에 덜 영향받도록 최상위 레이어에 띄운다. "1시간 동안 묻지 않기"는 `run_script`·`run_tests`용과 `call_sdk`용으로 나뉘고, 각 창에 적용 범위를 한 줄로 적는다. 2만 자 제한은 허용 기간에도 먼저 적용하며 실행하는 문자열 길이로 잰다. 허용 기간은 시스템 시계가 바뀌어도 흔들리지 않는 시계로 잰다.
